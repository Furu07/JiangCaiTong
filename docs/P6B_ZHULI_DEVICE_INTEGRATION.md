# P6B 住理生活设备集成

## 官方流程与接入条件

- MuMu 上的住理生活 3.12.9 使用现有应用状态。首页点选「江西财经大学麦庐园校区洗浴、直饮水项目」卡片，进入标题为「洗浴」的项目页。右上角「切换设备」打开「选择设备」，界面以楼栋、楼层和房间组织。洗浴页可见「设备号」字段。选择页未观察到空闲、占用或离线标签，也未看到连接确认按钮。
- 用户确认麦庐园可以在官方 App 选择设备并连接，流程无需蓝牙或必经扫码。本轮停在选择页，连接成功提示、状态更新、额外确认及开始、结束流程尚缺少获授权的现场证据。项目底层协议仍待服务方确认。
- 辛纳公开设备资料提及标准一卡通对接和第三方 App 支持。该资料面向设备及项目对接，本轮尚未取得可供酱菜通使用的授权流程、设备列表、状态、控制或消费接口文档。MuMu 中官方 App 的会话保留在官方应用内。[辛纳设备对接资料](https://www.whxinna.com/device/info/28)

## 代码落地

- `web/zhuli-device-page.js` 与 `web/index.html` 提供设备列表、楼栋和楼层筛选、房间和设备名称、刷新时间、当前选择及操作反馈。列表和可用状态仅接受授权适配器响应。交付版未配置适配器，显示真实的授权阻塞，列表和控制入口隐藏。官方 App 保留为备用入口。
- `web/zhuli-devices.js` 负责目录规范化、账户及项目作用域、刷新、设备选择和状态流转。适配器的作用域应代表当前授权、本人账户与校园项目。作用域变化时丢弃目录与选中设备，旧响应到达时也会被丢弃。列表更新失败保留同一作用域内的上次有效数据。当前状态仅保存在内存。
- 连接、核查、解除连接、开始和结束使用独立的适配器方法。同一时间只允许一项操作。状态回复必须对应所选设备，开始前需要经授权服务提供费用说明并由用户确认。异常或未确认的结果进入未知状态，锁住重复操作和设备切换，可核查状态或前往官方 App。
- 交付包沿用原有 Android 权限与网络桥。余额、设备实时状态、当前订单与历史记录均未通过酱菜通真实读取。

继续接入所需的最小材料是辛纳或学校确认本项目允许第三方接入，并提供授权、设备目录和状态查询说明。连接、开始与结束还需控制确认规则、结算状态查询，以及用户在本人设备旁授权的测试条件。
