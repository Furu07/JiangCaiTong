# P3C 考试安排

- 已授权门户的「课程考试 → 考试安排表」打开 `/student/ksap.sqhk.html`。读取器使用页面的 `xn`、`xn1`、`xq` 和考试批次 `xxlc`，仅执行「检索」。校方脚本将查询表单 POST 到 `/taglib/DataTable.jsp` 的考试报表，读取时核对新报表、已确认的报表类型与学期。
- 当前学期页面列出了四个批次。读取器按需查询同一学期的批次，全部返回校验通过的空表后才显示「暂无考试安排」。MuMu 已验证这一真实空结果。实测学校禁用了考试页学期控件，读取器对该页未开放的学期给出单独提示。
- 已确认报表表头含课程、考核方式、状态、考试时间等字段。考试行的转换、时间解析和展示只用合成数据验证。未识别的时间文字按校方原文展示。独立的地点、校区、座位、改期和未公布响应仍需有实际安排的报表验证。
- `web/jufe-record-reader.js` 与成绩共用教务授权，考试结果和错误由独立适配器管理。待办继续使用原有本机数据，本轮暂缓「添加到待办」。
