# P3D 学业成绩

## 0.6.3 有效成绩接入

- 用户指出应先选「有效成绩」再检索。用现有授权分别检查「入学以来」和 252 学期，校方均返回非空报表。252 学期的 11 条记录在本机校验通过，课程、学分、成绩、绩点逐行与校方字段一致。
- 读取器提交前选择「有效成绩」和「学期」，随后校验报表标题及学期并按表头映射课程／环节、学分、类别、修读性质、考核方式、成绩、获得学分、绩点、学分绩点和备注。查询结果保留在账号和学期隔离的内存缓存中。
- 「入学以来」用于本机核实校方格式。应用使用按学期查询，继续沿用原有学期选项。验证记录只保留状态、条数和字段匹配结论。
- 0.6.3 Debug 构建、签名和 MuMu 覆盖安装成功。应用切换到 252 学期后显示「有效成绩 · 11 条」，全程停留在主界面。8 项成绩读取及相关缓存定向测试通过。

## 0.6.2 记录

- MuMu 复用了现有教务授权。成绩页可选「入学以来」「学年」「学期」。保留门户默认的「原始成绩」和其余筛选项，仅执行一次「入学以来」检索。校方返回「没有检索到记录」，报表无表格。此前已查的 261、252 学期未逐一重查。
- `web/jufe-record-reader.js` 在按学期查询前明确选择校方「学期」控件，并在接收报表前再次校验范围。选择未生效或读取期间范围变化时返回格式错误，避免把其他查询范围的结果归到所选学期。已有账号隔离和失败缓存回退逻辑继续使用。
- 本轮实际核实了查询范围、学年和学期控件以及空报表结构。缺少真实非空样本，成绩、学分、绩点、课程性质、考核方式和补考／重修等明细字段仍待核验。范围校验通过定向合成测试。
- 后续只需在现有授权下打开一个确有已发布成绩的学期，由本机诊断核对脱敏表头与结构。
