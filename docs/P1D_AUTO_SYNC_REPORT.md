# P1D 江财教务授权与同步

验证日期为 2026-11-09，交付版本为 0.5.0 Debug。

## 实施与实测

- 课表页新增「绑定江西财经大学教务」。Android 9 及以上使用独立进程和 WebView 数据目录，Android 8 交给系统浏览器。独立窗口的顶层导航限于已核实的两个 HTTPS 主机，使用校方页面认证，应用桥接不注册到该窗口。MuMu Android 15 上已实测从课表页启动该窗口，系统日志记录了独立进程与 Activity 显示。 [Android WebView 数据目录](https://developer.android.com/reference/android/webkit/WebView#setDataDirectorySuffix(java.lang.String))
- 本轮未登录实测官方入口返回 HTTP 302，目标为 `ssl.jxufe.edu.cn/cas/login`，公开 `service` 参数指回 `jwxt.jxufe.edu.cn//jxcjcaslogin`。尚无获准的应用授权交接、本人课表路径及响应证据。生产版学校传输和原始解析槽保持未配置，打开页面或完成跳转均不会标记已绑定。 [江西财经大学教务处](https://jwc.jxufe.edu.cn/) · [本科教务入口](https://jwxt.jxufe.edu.cn/jxcjcaslogin)
- Debug 窗口可在用户打开本人课表后检查本机结构。返回主界面的摘要仅含表格、框架和行数以及预定义表头标签，无页面内容和认证数据。
- `web/jufe-sync.js` 已接入课表界面与既有适配器。经过验证的候选授权会读取当前学期和本人课表，成功后才发布绑定。重新打开先读缓存，具备有效授权时按 6 小时新鲜度刷新，30 秒内限制重复尝试。学期切换、手动刷新、会话过期提示、同账号同学期原子替换、失败回退和未经确认的空响应保护已实施。保留 JCT 导入，统一时段模型新增可选课程代码。

43 项离线断言通过。首次授权自动查询、恢复授权按需同步、账号隔离、并发去重、空响应保护和过期回退均使用合成传输验证。**江财真实课表获取、首次授权后的真实自动同步和重开后的真实同步尚未验证。**
