日期为 2026-11-09。版本为 0.2.0 Debug。

## 公开事实与接入边界

| 证据 | 核对结果 |
| --- | --- |
| 教务处网站 | 本科教务链接为 `https://jwxt.jxufe.edu.cn/jxcjcaslogin`，选课平台为另一个入口。 [江西财经大学教务处](https://jwc.jxufe.edu.cn/) |

既有研究里的登录 POST 参数、加密方式、学期列表及个人课表 API 的路径、请求方法和响应字段均缺少授权后的证据。APK 只通过系统浏览器打开已经核实的公开入口。真实查询传输暂未配置。

## 代码与定向测试

- `web/academic.js` 定义学期、上课时段和教学周映射。同一课程可有多条时段。保留校区、教学楼、节次、单双周和离散周。按具体日期或周次应用调课，支持停课、特殊安排和重叠标记。示例 UI 可切换两个学期。
- `web/jufe-academic.js` 提供可注入的只读传输及 HTML/JSON 解析接口。随包解析器只识别自定义的 `jct-timetable/1` 交换格式。授权句柄留在内存，适配器区分未连接、已授权和过期。会话切换后丢弃旧请求结果。
- 缓存按适配器、账号作用域及学期分区。同步失败只回退当前账号同一学期的数据，并保留上次同步时间。退出后当前界面无权读取该账号缓存。P0B 的示例缓存仍可读取。
- JavaScript 与构建脚本语法检查通过。20 项离线断言覆盖双格式、时段、日历例外、数据校验、过期、缓存回退、切换账号和并发隔离。另有 8 项浏览器界面断言，详见 [P0C 验证](P0C_RUNTIME_VALIDATION.md)。

在仓库根目录执行 `py -3.12 -m http.server 8765 --bind 127.0.0.1`，用浏览器打开 `http://127.0.0.1:8765/tests/academic.html` 即可重跑离线解析测试。测试页面只读取本机合成样本。

## 下一步需要的授权样本

用户自行在官方页面完成认证后，优先提供本人课表的一份脱敏 HTML 表格或 JSON 响应片段，以及学期选择列表和教学周起始日期。样本最好涵盖同课多时段、单双周和一条调课记录。保留字段名、嵌套关系和空值形式，去除账号、姓名、学号、Cookie、Token、验证码和完整请求记录。如果可以提供经核实的只读请求路径与方法，用纯文本记录即可。

拿到样本后先固化实际格式与失败响应，再接入经过确认的只读查询。随后用可用 Android 设备验证学校授权交接与会话过期，复验学习通桥接隔离与 Keystore。
