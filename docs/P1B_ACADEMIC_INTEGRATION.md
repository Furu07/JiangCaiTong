# P1B 江财教务接入

日期为 2026-11-09。交付版本为 0.3.0 Debug。

## 已核实的认证入口

- 江财教务处公布的本科入口是 `https://jwxt.jxufe.edu.cn/jxcjcaslogin`。未登录实测返回 HTTP 302，进入 `https://ssl.jxufe.edu.cn/cas/login`，其公开 `service` 参数指向 `https://jwxt.jxufe.edu.cn//jxcjcaslogin`。该参数说明预期返回目标，认证后跳转、票据处理和教务 Cookie 建立过程仍待授权确认。 [教务处](https://jwc.jxufe.edu.cn/) · [本科教务入口](https://jwxt.jxufe.edu.cn/jxcjcaslogin)
- 公开资料说明学校运行统一身份认证。本轮公开核对范围内，未找到酱菜通可使用的第三方授权登记、回调或课表 API 说明。既有报告中 `/cas/login.action` 的 POST 参数及课表路径缺少授权证据。 [学校统一身份认证指南](https://nic.jxufe.edu.cn/news-show-1270.html)
- Android WebView 由应用管理自己的 Cookie。系统浏览器登录只供用户访问学校官网，酱菜通不会据此标记已登录或读取浏览器 Cookie。 [Android CookieManager](https://developer.android.com/reference/android/webkit/CookieManager)

## 认证与会话交接

优先向学校确认第三方应用授权和只读课表权限。若学校提供注册流程，由用户在官方页面认证，再通过校方认可的回调和授权方式建立应用会话。若学校允许自有 WebView 承载登录，可验证独立、无敏感 JS Bridge 的窗口，限制已核实的 HTTPS 主机，由用户在原页面完成验证码和其他校验。先确认登录后的只读课表请求、账号归属、会话范围与失效响应，再决定同一 WebView 内完成查询，或由原生层接管经校方允许的最小会话。两条路径均应通过本人课表读成功确认授权，并在 401、确认的登录跳转或其他有证据的过期信号出现时撤销本地授权。

本轮继续用系统浏览器打开官方入口。真实传输和在线同步按钮待授权协议与真实接口确认。适配器保留手动同步及同账号同学期回退逻辑，区分过期、拒绝访问、限流、服务异常、连接和格式错误。错误回退保留原同步时间。

## 本地脱敏样本导入

课表页进入「江财本科教务 → 导入脱敏课表」，选择 UTF-8 的 JCT 交换格式 JSON 或 HTML，也可粘贴同格式文本。验证通过后只保存规范化课程、学期和导入时间，导入记录与示例和未来授权缓存分开。按学期切换、重读和移除均可离线完成。同一导入学期可更新，错误样本保留已有记录。文件上限为 256 KB，支持最多 12 个导入学期。

当前格式依据 [JSON 合成模板](../tests/fixtures/jct-timetable.synthetic.json) 和 [HTML 合成模板](../tests/fixtures/jct-timetable.synthetic.html)。导入拒绝未定义字段、非课表标签、无效节次和周次。本轮仓库中只有合成样本，学校原始课表结构的解析待样本验证。样本格式的字段检查无法识别填写在合法文本字段里的个人信息，请先人工脱敏。

## 用户需要完成的最小步骤

1. 在系统浏览器打开[本科教务入口](https://jwxt.jxufe.edu.cn/jxcjcaslogin)，自行完成学校认证，然后打开本人课表并选择一个学期。
2. 提供一小段脱敏的课表表格 HTML 或对应请求的 JSON 响应。若使用浏览器开发者工具，仅从该课表请求的「响应」面板复制相关内容。附上学期标识、第一教学周周一、教学周总数及已知跳周。若已确认只读请求，可另附请求方法和路径。
3. 保留原字段名、嵌套结构、时间、节次和周次。将姓名、学号、账号等值替换为占位符，去除 Cookie、Token、密码、验证码及带认证参数的 URL。只提交脱敏片段。若希望先在手机上看课表，可把课程手动整理进上面的 JCT 模板后导入。

下一步优先用这份片段实现学校格式解析器，并复核权限、过期和空课表的真实响应，再配置授权传输。
