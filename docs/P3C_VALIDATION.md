# P3C 定向验证

## MuMu Android 15

- 0.6.1 Debug 以覆盖方式安装。冷启动显示江财课表，进入成绩、考试和切换学期均留在主界面。
- 在应用内使用既有授权查询 261 和 252 学期成绩，均得到校方空报表。回到成绩页时复用内存结果，更新时间保持原值。
- 261 学期考试批次均返回通过结构校验的空报表。应用切换到 252 后显示「校方页面未开放查询所选学期」，原因是校方锁定了考试页学期控件。非空报表、明确的未公布响应和实际改期尚待有数据的授权会话验证。
- 修正了把统一认证中间跳转提前判为过期的问题。成绩、考试仅从校方个人课表表单核对账号，避免等待课表网格。静默课表刷新优先打开已确认的门户首页，需要时回退原入口。最终 APK 的课表静默刷新成功，更新时间更新为 `14:49:30`，主界面未弹出登录。待办页在教务查询后可正常打开。
- 独立教务查询有前端超时及请求编号，用于结束未返回的读取并忽略迟到结果。
