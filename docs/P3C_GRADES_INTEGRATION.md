# P3C 学业成绩

- 已授权门户的「学业成绩」打开 `/student/xscj.stuckcj.jsp`。原生读取器只操作页面的学年按钮、学期选项及「检索」。实测 `xn`、`xn1` 和 `xq` 控制起止学年与学期，第一、第二学期对应页面选项 `0`、`1`。
- 校方表单以 POST 提交到 `/student/xscj.stuckcj_data10421.jsp`，结果在同源 `frmReport` 内。读取器要求查询后的新报表文档以及校方的「没有检索到记录」标记，才显示「暂无成绩」。
- `web/jufe-record-reader.js` 实现官方页导航与空报表识别。`AcademicSyncService` 在同一隔离 WebView 中先核对本人课表的账号，再读取成绩。`web/academic-records.js` 提供账号与学期隔离的内存缓存及错误回退，成绩不写入本地持久存储。
- 当前账号查询返回校方空报表，尚无非空成绩报表、明确未发布标记或官方绩点汇总可校验。遇到未知报表会显示格式错误。要继续接入成绩明细，只需用同一授权打开一个校方已有成绩的学期，以便核对脱敏表头和结构。
