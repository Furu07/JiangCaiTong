## 0.7.0 交付包复查

- 学习通使用现有会话。在 MuMu 手动隐藏一门原本显示的课程，展开隐藏列表可看到隐藏原因，并可打开课程历史作业。切换到待办再返回学习页，隐藏列表仍处于展开状态。验证后恢复课程显示。
- MuMu 自带输入法本次报告已显示，窗口高度为 0。临时切换到本地测试输入法，在 360px 宽度确认 Android 实际显示高 304 CSS px 的软键盘。键盘刚弹出时保存按钮部分被遮住，向上滚动编辑弹层后完整可见。实测用键盘输入一个字符，再直接点击保存，修改成功。验证后删除合成待办，恢复原输入法、尺寸和密度，移除测试输入法。
- 教务会话过期时，冷启动继续显示真实课表缓存，手动刷新后停留在主界面并提示主动重新绑定。用户完成校方认证后，课表重新同步。原有 30 秒间隔结束后手动刷新，后台记录 `background result success`，同步时间推进，应用始终留在主界面。未等待 6 小时触发自动刷新。
- 成绩页显示校方返回的四个历史学期。从 252 切至 251 后显示对应的真实记录，后台读取成功；切回 252 后显示原记录和缓存时间。全程复用同一教务授权，未出现登录窗口。验证未保存成绩明细或包含成绩的截图。
