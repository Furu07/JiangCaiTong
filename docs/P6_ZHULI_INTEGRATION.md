# P6 住理生活基础集成

- 「生活」使用 P5 的分段按钮、卡片、状态提示和深浅主题。默认显示校园饮水，切到校园洗浴可查看已核实的麦庐园项目及官方服务入口。从「我的」进入 798 时直接打开饮水子页。
- `web/zhuli.js` 是独立适配器，区分官方 App 可打开、需要应用宝入口、当前环境不可用。切换服务及返回应用时刷新入口状态。页面将账户和使用记录指向官方 App，由用户在其界面操作。
- Android 桥接和 Manifest 只添加住理生活的指定包查询和启动能力。打开时重新检查包的启动入口，应用缺失或启动失败时转到应用宝详情页。现有慧生活798外部入口使用同一启动机制和原有地址，短信配置、原生查询和存储沿用原实现。
- 当前功能只处理外部入口，因此住理生活没有写入酱菜通 Keystore、Cookie、账户缓存或网络请求白名单。后续原生查询需要服务方提供授权能力，再使用独立账户域接入。余额、设备状态、消费记录和设备控制均未接入酱菜通。APK 沿用已有权限。
