# P3A 教务模块

- 「教务」默认打开「我的课表」。成绩、考试各自保留选择的学期，学期选项来自已绑定的江财教务。切换栏目只更新界面和查询状态。
- 保留课表同步、账号隔离、周／日视图与缓存。MuMu 覆盖安装后读到了原有课表，冷启动后台刷新返回成功，前台仍为主界面。
- 成绩与考试共用现有教务窗口和授权状态。「在校方教务查看」由用户点击打开，MuMu 中复用了原有教务会话。已失效或未绑定时，页面提供返回课表绑定的入口。
- 新增独立的标准化适配器，分别处理成绩和考试字段，区分空结果、未发布、会话失效、网络和格式错误。带数据源时只在内存按当前账号和学期缓存，切换账号或授权失效时隔离在途结果。成绩列表展示学校提供的字段，考试列表按日期与时间排列。
- 成绩、考试的应用内正式查询仍待接入。现有证据只足以确认官方本科教务入口和页面导航，学期参数、本人数据响应以及空数据和未发布的区分仍需脱敏验证。实际构建的两页显示待核实提示，未配置成绩或考试数据源，也没有持久保存这两类记录。

官方入口来源：[江西财经大学教务处](https://jwc.jxufe.edu.cn/)。
