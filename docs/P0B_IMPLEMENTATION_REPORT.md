## 实际实施

| 范围 | 已落地内容 |
| --- | --- |
| Android 工程 | 独立的 `android/` 与 `web/`，资源标识为「酱菜通 / JiangCaiTong」，应用 ID 为 `com.jxufe.jct`。最低 API 26，目标 API 33。自有矢量图标，APK 内附原作者版权与 MIT 许可。 |
| 导航与页面 | 四项底部导航为课表、学习、生活、我的。沿用上游浅色与深色主题、按钮、卡片和底部弹层。迁移清单排除了郑航百科、公告、校历、成绩、办事入口及更新下载器。 |
| 江财课表基础 | `web/academic.js` 定义结构化 `JufeAcademicAdapter` 契约及课程、学期模型。示例适配器支持周次区间、单双周、跨段和离散周。主页面支持周视图、日视图、周次切换、课程详情及同步状态。课表缓存按适配器分区并校验版本和模型。 |
| 学习通 | 复用上游课程、作业、考试和活动的查询与解析。用户在独立 WebView 完成超星官方页面登录，再主动导入学习通 Cookie。查询从课程列表进入单门课程，显示独立查询失败状态，结果可从本机缓存读取。打开登录窗口时清除旧学习缓存，以隔离可能的账号切换。 |
| 慧生活798 | 迁移设备账号验证码登录及余额、设备、消费记录查询。短信由用户主动触发和填写。设备列表可从本机会话缓存恢复。Java 桥接将798网络请求限制在验证码登录和三类查询路径。 |
| 运行边界 | 本地页面与官方登录 WebView 分离。查询使用 HTTPS，App 保存的学习通 Cookie 和798会话分字段使用 Android Keystore 与 AES-GCM。保留 WebView 缓存清理能力。学习通使用平台的 WebView Cookie 存储完成登录交接，并在退出时清理该存储。 |

Android 调试构建使用 `py -3.12 android/build_apk.py`，生成 `D:\项目\jct\android\dist\JiangCaiTong-0.1.0-debug.apk`。签名使用酱菜通独立本地 Debug 密钥，构建和校验结果见[验证报告](P0B_VALIDATION.md)。

## 待验证与后续接入

- 江财教务仍处于示例阶段。下一步由用户在官方页面自行登录，在授权范围内收集脱敏的课表响应或 HTML、学期周历，以及单双周、调课、跨校区和同一课程多时段样本。先用离线样本验证模型转换，再接入已确认的只读路径和按账号隔离的缓存。
- 学习通的官方登录、验证码或跳转、WebView Cookie 导入及真实课程查询需要 Android 设备与用户授权。P0B 采用手动按课查询。
- 慧生活798需要用江财宿舍的实际账号验证登录协议及余额、设备、消费记录。接水控制、充值、兑换、扣费和自动签到均不在本轮实现范围。
- `adb devices -l` 未列出设备。APK 的安装、启动、原生 Keystore 运行及 Android 8 设备实际兼容性仍待设备验证。
