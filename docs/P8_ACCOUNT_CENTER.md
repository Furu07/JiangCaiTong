# P8 统一账号管理

「我的 → 账号管理」采用航院通 0.52.1（构建号 157）`accState`、`ACC_SYS` 和 `renderAccounts` 的服务列表模式。慧生活设备和积分各自显示一行。账号页只展示连接状态和操作，课表、任务、余额及账单仍在业务页。

| 服务 | 连接与断开 | MuMu 实际验证 |
| --- | --- | --- |
| 江西财经大学教务 | 复用校方隔离认证窗口。断开仅清除教务 WebView 会话及绑定，按账号保存的课表缓存保留。 | 显示已有绑定的会话过期状态。重连进入官方窗口，取消后返回。断开及课表隔离通过定向测试，未清除实际教务会话。 |
| 超星学习通 | 复用隔离登录及原生会话恢复。断开清理学习通会话与对应课程缓存。 | 显示已连接，重连进入原认证窗口，取消后返回。原授权已成功查询。未执行实际退出或账号切换。 |
| 慧生活798 设备 | 复用 P7F 短信登录及独立设备 Token，提供重连及断开，手机号仅显示掩码。 | 已读到保存的会话。打开原表单及验证码后取消，饮水业务仍可访问。 |
| 慧生活798 积分 | 使用同一表单、独立积分 Token，分别连接及断开。 | 显示未连接。按既定安排暂缓真实登录。 |
| 住理生活 | 显示未接入酱菜通账号，沿用外部官方应用入口。 | 状态与现有能力一致。未验证官方应用的账号。 |

教务 Cookie 清理由 `AcademicSyncService` 在独立教务进程执行。学习通仍使用自己的 Cookie 容器和账号作用域。798 协议及原配置来源沿用 P7F。MuMu 覆盖安装后冷启动停在主界面，五项底部导航和账号页返回操作可用。此次实测未出现重复打开认证页。双账号及旧请求隔离使用定向测试验证，实际会话未被清除。
