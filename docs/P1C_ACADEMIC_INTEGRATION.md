课表页的「导入脱敏课表」可选择 JCT 交换格式或学校原始样本。前者继续生成离线课表。后者可选 UTF-8 文件或粘贴片段，在本机检查 JSON 根结构或 HTML 表格数量。当前仅显示结构摘要，原文不持久化。登录表单和明显的抓包文档会被拒绝。原始样本仍需人工脱敏。

JCT 的有效空课表会显示专门的空状态。如果同学期已有课程，只有用户明确确认后才能用空数据覆盖。结构不明、校验失败或写入失败均保留旧数据。

用户自行在官方页面登录后，只需提供一小段脱敏的本人课表 HTML 或 JSON 响应、学期标识和第一教学周日期及周数。保留原字段与嵌套层级，移除账号、身份、Cookie、Token、验证码及请求头。拿到样本后先实现对应格式解析与空课表、过期响应判别。自动同步还需校方认可的授权方式，系统浏览器与应用会话继续分离。
