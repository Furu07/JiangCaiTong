# P3D 考试安排

- MuMu 上的校方考试页仍锁定学年和学期，只开放 261 学期，显示四个考试批次。沿用 P3C 对这四个批次的真实空报表验证，本轮未重新提交批次检索，也未改写校方的学期参数。
- 已核实的报表列含课程、学分、类别、考核方式、修读性质、状态、考试时间及审核状态。缺少真实非空样本，地点、校区、楼栋、座位及改期字段仍待核验。
- `web/jufe-record-reader.js` 只有在日期有效且起止时间顺序成立时才拆分考试时间。自然语言、无效日历日期及无法确认是否跨日的时间段保留校方原文。该行为仅用合成数据验证。
- 现有待办持久化沿用原实现。取得并校验真实考试明细后，才能验证从考试创建待办所需的时间和课程字段。
